# Irish-Pub
## 🍺Концепт-сайт ирландского паба🍺
👉[Открыть веб-сайт](https://romka005.github.io/Irish-Pub/)👈

**Сайт паба с более чем двадцатилетней историей — можно посмотреть меню, узнать расписание трансляций на сегодня.**

## 🍻 О проекте

Культовый ирландский паб с барной стойкой на 15 метров, VIP-залом и летним двориком-колодцем. Сайт объединяет меню, афишу спортивных трансляций и программу лояльности в одном месте.

## ✨ Функционал

- 🍺 Интерактивная барная стойка — наведи курсор на предмет (пиво, кухню, бар, афишу) и попадёшь в нужный раздел меню с мини-анимацией
- 🍔 Меню с вкладками "Кухня / Бар / Пиво" и фильтром по категориям блюд
- 📺 Афиша трансляций с лентой дат, автоопределением сегодняшнего дня и live-статусом матча, который идёт прямо сейчас
- 🎟 Программа лояльности "Клуб друзей" с партнёрскими заведениями
- 📍 Страница контактов со встроенной картой и индикатором "открыто / закрыто" по реальному времени
- 🪑 Онлайн-бронирование стола через виджет Restoplace
- 📱 Адаптивный дизайн с плавающей кнопкой навигации на мобильной версии
